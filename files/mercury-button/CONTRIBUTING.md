# Contributing

Thanks for helping improve mercury-button.

## Setup

```bash
git clone https://github.com/YOUR-USERNAME/mercury-button.git
cd mercury-button
npm install
npm run dev
```

Open `http://localhost:5173/demo/`. To test tilt on a phone, open the same URL over your local network, or use Chrome DevTools > More tools > Sensors to simulate orientation.

## Project layout

```
src/     source files you edit
dist/    build output (regenerated by npm run build)
demo/    demo page, also deployed to GitHub Pages
```

## Guidelines

- Keep the library dependency-free.
- CSS uses BEM: `.mercury-button`, `.mercury-button__element`, `.mercury-button--modifier`, and `is-*` for states.
- New visual options should be CSS custom properties or modifier classes, not JS options.
- Anything that runs every frame must avoid layout reads and skip work when values have not changed.
- Test on at least one real Android device when touching the filter, loop or sensor code.
- Respect `prefers-reduced-motion`.

## Commits

Use short, imperative messages. Prefixes help the changelog:

```
feat: add copper variant
fix: stop slosh jitter when phone is flat
perf: skip surface solve for hidden buttons
docs: clarify iOS permission flow
```

## Pull requests

1. Fork the repo and create a branch from `main`.
2. Make your change in `src/`.
3. Run `npm run build` and check the demo.
4. Add a line under `Unreleased` in `CHANGELOG.md`.
5. Open a pull request and fill in the template.

## Adding a variant

Add a modifier near the other modifiers in `src/mercury-button.css`:

```css
.mercury-button--copper {
  --mb-metal: #b87a55;
  --mb-metal-rgb: 214, 150, 110;
}
```

Then add a row to the Modifiers table in `README.md` and a button to `demo/index.html`.
